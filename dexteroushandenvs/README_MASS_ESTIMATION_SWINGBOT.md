# 基于SwingBot方法的物体质量估计

## 概述

`estimate_mass_swingbot.py` 实现了基于SwingBot论文方法的物体质量估计。该方法通过机器人本体的自感知（关节力矩）来估计物体质量，不需要外部力传感器。

## 核心思想

### SwingBot方法要点

1. **探索运动**：
   - **倾斜（Tilting）**：机器人握持物体并进行倾斜，观察物体在重力作用下的响应
   - **摇晃（Shaking）**：机器人对物体施加振动，分析物体的动态特性

2. **自感知**：
   - 使用机器人本体的关节力矩传感器
   - 不需要外部力传感器（如GelSight等触觉传感器）

3. **物理模型**：
   - 通过关节力矩和雅可比矩阵反推末端执行器接触力
   - 使用动力学方程估计物体质量

## 当前实现

### 方法1：基于加速度响应（已实现）

**原理**：
- 执行摆动运动，收集末端执行器和物体的加速度数据
- 如果物体与手有良好接触，它们的加速度应该接近
- 质量大的物体，对于相同的输入，加速度响应较小（惯性大）
- 使用加速度的统计特性来推断质量

**优点**：
- 实现简单
- 不需要复杂的动力学模型

**缺点**：
- 精度有限
- 需要校准参数

### 方法2：基于关节力矩和雅可比矩阵（框架已提供）

**原理**：
1. 关节力矩方程：`τ = J^T * F_contact + τ_robot`
2. 反推接触力：`F_contact = (J^T)^(-1) * (τ - τ_robot)`
3. 动力学方程：`F_contact = m * (a_ee + g)`
4. 估计质量：`m = F_contact / (a_ee + g)`

**需要**：
- 雅可比矩阵（Isaac Gym可以获取）
- 机器人基线力矩（无物体时的力矩，用于减去）
- 或者完整的机器人动力学模型

### 2. 使用基线力矩

**方法**：
1. 先运行一次无物体的摆动运动，记录基线力矩 `τ_baseline`
2. 然后运行有物体的摆动运动，记录总力矩 `τ_total`
3. 接触力矩：`τ_contact = τ_total - τ_baseline`
4. 使用 `F_contact = (J^T)^(-1) * τ_contact` 计算接触力

### 3. 使用最小二乘法

收集多个数据点，通过最小二乘法求解：

```
min ||τ_contact - J^T * m * (a_ee + g)||^2
```

## 注意事项

1. **接触检测**：需要确保物体与末端执行器有良好接触
2. **运动设计**：摆动运动应该能够激发物体的动态响应
3. **数据质量**：需要足够的有效数据点（建议>50个）
4. **参数校准**：简化方法中的参数需要根据实际机器人校准
