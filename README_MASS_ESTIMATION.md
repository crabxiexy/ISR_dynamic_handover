# 物体质量估计脚本说明

## 概述

`estimate_object_mass.py` 脚本实现了通过让投掷机械臂执行简单运动来估计物体质量的功能。

## 功能

1. **环境创建**：按照 `create_env` 的逻辑导入物体和投掷机械臂（左手）
2. **运动执行**：让机械臂执行上下运动
3. **数据收集**：收集物体的位置、速度、加速度等运动学数据
4. **质量估计**：使用物理方程估计物体质量
5. **结果比较**：与实际质量进行比较

## 使用方法

```bash
cd /home/caozhuo/dynamic_handover
python estimate_object_mass.py
```

## 代码结构

### 主要类：MassEstimator

- `__init__()`: 初始化 Isaac Gym 仿真环境
- `create_environment()`: 创建物体和机械臂
- `run_motion_and_collect_data()`: 执行运动并收集数据
- `estimate_mass()`: 估计物体质量
- `run()`: 运行完整的质量估计流程

## 当前限制

⚠️ **注意**：当前实现使用的是简化方法，因为：

1. **缺少力传感器数据**：无法直接测量物体与手之间的接触力
2. **接触力索引问题**：Isaac Gym 的接触力张量索引需要精确匹配刚体顺序
3. **简化估计方法**：使用启发式方法而非精确的物理模型

## 改进建议

### 1. 使用力传感器

如果机械臂或手部有内置力传感器，可以：

```python
# 获取力传感器数据
self.gym.refresh_force_sensor_tensor(self.sim)
force_sensor_data = gymtorch.wrap_tensor(...)
```

### 2. 使用 DOF 力矩数据

通过关节力矩可以反推作用在物体上的力：

```python
self.gym.refresh_dof_force_tensor(self.sim)
dof_forces = gymtorch.wrap_tensor(...)
# 使用雅可比矩阵将关节力矩转换为末端执行器力
```

### 3. 更精确的物理模型

使用完整的动力学方程：

```
F_contact = m * (a_measured - a_gravity) + F_friction + ...
```

### 4. 使用系统辨识方法

- 收集多个运动轨迹的数据
- 使用最小二乘法或卡尔曼滤波估计质量
- 考虑摩擦、惯性等因素

## 实际应用建议

对于实际的质量估计任务，建议：

1. **使用真实的力传感器**：在机械臂末端或手指安装力/力矩传感器
2. **设计专门的运动轨迹**：执行已知的加速度轨迹，测量所需的力
3. **多次测量取平均**：执行多次运动，使用统计方法提高估计精度
4. **考虑不确定性**：提供质量估计的置信区间
